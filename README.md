## Publicação no GitHub Pages
1. Crie um repositório chamado `Monitor-30D`.
2. Envie `index.html` para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em Build and deployment, selecione **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`, e salve.

Os dados da ferramenta ficam armazenados localmente no navegador. Use **Exportar backup** para salvar uma cópia dos registros.
